# Community export scripts

Export scripts contributed by preFlight users, one folder per script.

To contribute, start from [export_template.py](../export_template.py) and follow
[Contributing a script](../../README.md#contributing-a-script).

These scripts are used at your own risk. An export script writes to your filesystem and
talks to your network with full access to both. Read and configure a script before running
it. See [Use at your own risk](../../README.md#use-at-your-own-risk).
