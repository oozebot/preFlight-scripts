# Community preprocessing scripts

Preprocessing scripts contributed by preFlight users, one folder per script.

To contribute, start from [process_template.py](../process_template.py) and follow
[Contributing a script](../../README.md#contributing-a-script).

These scripts are used at your own risk. They were written for other printers and other
materials. Read and tune a script before running it. See
[Use at your own risk](../../README.md#use-at-your-own-risk).
